Stage · Estatmar · février – août 2026

MedExtract AI

Plateforme qui transforme des bilans sanguins scannés en données structurées, et un assistant qui aide à les lire, sans jamais poser de diagnostic.

IA appliquéeOCRNLP / RAGÉquipe de 4
01

Ma contribution

J'ai conçu l'ensemble de la plateforme puis réparti les modules entre les membres de l'équipe. Le dépôt GitHub regroupe le projet complet.

Comment ça marche

1
Lecture du documentOCR du bilan scanné (PaddleOCR) : mots et positions sur la page.
2
Extraction des analysesRègles (regex) toujours disponibles, et modèle LayoutLMv3 fine-tuné sur le texte + la mise en page (étiquettes BIO : analyse, valeur, unité, référence, patient, date). Objectif visé : F1 ≥ 0,75.
3
Interprétation des normesChaque valeur est comparée à ses normes de référence → statut NORMAL / HIGH / LOW.
4
Assistant RAG localMistral via Ollama, en local : les données de santé ne partent vers aucune API externe.
5
ExportRésultats exportables en Excel, historique des analyses par utilisateur.

Stack

FastAPI · microservicesPaddleOCRLayoutLMv3Ollama + MistralPostgreSQLReact 18 / TypeScriptDocker ComposeNginxJWT
Voir le code sur GitHub →

Exemple de résultat structuré

AnalyseValeurNormesStatut
Glycémie1,15 g/L0,70 – 1,10HIGH

↳ Exemple tiré de la documentation du service IA : 1,15 > 1,10, donc la valeur est signalée « HIGH ».

Garde-fous du chatbot

  • Une question de type diagnostic est refusée, avec une orientation vers un médecin.
  • Aucun traitement ni aucune dose : les termes concernés sont neutralisés dans les réponses.
  • Un avertissement médical est ajouté à chaque réponse.
  • Si le modèle est indisponible, l'assistant répond depuis sa base de connaissances (glycémie, cholestérol, hémoglobine, vitamine D, TSH, créatinine).
Est-ce que j'ai du diabète ?
Je ne peux pas poser de diagnostic ni recommander de traitement. Ces analyses doivent être interprétées par un médecin qui connaît votre situation complète. Je vous invite à consulter un professionnel de santé.
Texte de refus tel qu'il est codé dans le module de sécurité du chatbot (safety.py).

⚠︎ MedExtract AI est un outil d'aide à la lecture et à la saisie. Ce n'est pas un système de diagnostic médical.

Stage · Estatmar · 2026

QuoteFlow

Plateforme de gestion de devis : le client fait sa demande, un employé produit un devis chiffré en PDF, un administrateur supervise l'activité.

BackendSécuritéAutomatisationÉquipe de 4
03

Ma contribution

Authentification et sécurité (Spring Security + JWT), et génération et mise en page des devis PDF.

Sécurité

  • Authentification JWT sans état, mots de passe hachés avec BCrypt
  • Accès par rôles CLIENT / EMPLOYE / ADMIN avec @PreAuthorize
  • Secret JWT lu depuis une variable d'environnement (aucun secret dans le dépôt)

Côté projet

  • Messagerie en temps réel (WebSocket / STOMP)
  • Emails automatisés via des workflows n8n
  • API documentée et testable avec Swagger, base H2 de démonstration

Stack

Java 17 · Spring Boot 3Spring Security · JWTiText 7WebSocket / STOMPn8nMySQL · H2React / ViteSwagger
